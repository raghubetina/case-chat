# Vesta seed documents

These learner-safe files come from the Vesta teaching package the project owner
supplied for use in this prototype and which was reviewed on 2026-08-13. The
original authorship and public redistribution terms are not recorded, so these
files are excluded from the repository's MIT license and must not be published
or redistributed separately without the project owner's confirmation. The
eventual development seed attaches them to document bundles owned by the
appropriate stakeholders.

- `data_door_log.csv` — Tessa Kimura
- `data_kitchen_tickets.csv` — Marco Devlin
- `data_checks.csv` — June Ellery and Tessa Kimura
- `data_takeout_forecast.csv` — Owen Brandt
- `platform_terms.md` — Owen Brandt
- `loyalty_summary.md` — June Ellery

The door log is preserved verbatim, including its single `left the line` value
among otherwise equivalent `left at the door` outcomes. Analysis that groups
walk-aways must treat both labels alike.

Do not copy `ground_truth.json`, `branch_map.csv`, instructor notes, simulation
outputs, or solution files into this directory. Those sources are author-only
evaluation material and must never be released to learners or inserted into a
stakeholder prompt.
